Возвращаемся к range(). Давай зафиксируем саму суть: эта функция нужна только для генерации последовательности чисел. Чаще всего — чтобы запустить цикл for определенное количество раз.

У неё есть три варианта использования, давай по шагам:

1. Передаем одно число: range(стоп)
Генерирует числа от 0 до указанного числа (не включая его).
for i in range(3):
    print(i)  # Выведет: 0, 1, 2

Зачем: Когда тебе нужно просто повторить какое-то действие $N$ раз.


2. Передаем два числа: range(старт, стоп)
Генерирует числа от первого до второго (опять же, не включая второе).
for i in range(5, 8):
    print(i)  # Выведет: 5, 6, 7

Зачем: Когда нужно начать отсчет не с нуля (например, номера серверов со 101).

3. Передаем три числа: range(старт, стоп, шаг)
Генерирует числа от первого до второго с определенным шагом.

for i in range(2, 9, 2):
    print(i)  # Выведет: 2, 4, 6, 8

Зачем: Когда нужно пропустить элементы (например, только четные IP-адреса).

Важнейшее правило: Правая граница (стоп) никогда не включается в результат. Если нужно число включительно — всегда пишем + 1.

len() работает со всем, у чего есть структура «внутри меня лежит несколько элементов». Если объект цельный (как число 150, логическое True или пустота None), len() на нём сломается.
